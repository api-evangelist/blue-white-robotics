# Blue White Robotics (Bluewhite)

> Israeli off-road autonomy company (founded 2017, Tel Aviv + Fresno, California) that
> retrofits conventional vehicles into unmanned ground vehicles. Two products: Pathfinder,
> an OEM-agnostic aftermarket autonomy kit built from control, intelligence and perception
> modules over a distributed CAN network, and Compass, a cloud fleet-operations SaaS for
> remotely supervising, tasking and monitoring an autonomous fleet. Started in permanent-crop
> agriculture (~150,000 US acres, 20+ growers) and extended the same GPS-denied navigation
> and perception stack into defense and homeland-security ground robotics. Acquired in full
> by Elbit Systems' FUSE in 2026.

## API surface

Bluewhite markets a "Software SDK" and an "API platform" on its technology page for OEM and
system integration, but as of 2026-08-07 it publishes **no public developer portal, no API
reference, and no machine-readable specification** — no OpenAPI, AsyncAPI, GraphQL SDL,
Postman collection, MCP server or A2A agent card was found on any Bluewhite host. The
Compass operator platform is gated by an OIDC authorization-code flow against a Keycloak
realm (`maia-cloud`, client `maia-prod`) at `auth.bluewhite.ai`, and SDK/API access is
routed through the contact-sales form. Treat every capability below as marketing copy, not
as a callable contract.

- [Technology / integration methods](https://www.bluewhite.ai/technology): "Bluewhite
  technology can be implemented in various methods and support integrations through our API
  platform." Integration paths named: Aftermarket Kit, OEM Integration, Software SDK.
- [Contact](https://www.bluewhite.ai/contact): the only route to SDK or API access.
- [Compass operator platform](https://compass.bluewhite.ai/): customer login; every path
  302s to the Keycloak realm.
